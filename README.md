# 健身饮食打卡

记录每天的饮食和训练，按规则月底结算奖金或罚款。网页版 App，可以添加到 iPhone 主屏幕，数据只存在手机上。

## 装到 iPhone

1. 用 **Safari** 打开发布后的网址
2. 点底部的「分享」按钮 →「添加到主屏幕」
3. 以后从主屏幕图标打开，断网也能用

> Safari 里和主屏幕图标里的数据是分开的，请只用主屏幕图标打卡。
> 每月在「规则 → 数据备份」导出一次备份。

## 功能

- **今日**：奖金卡、饮食（按餐记录、违禁检查、放纵日、申请豁免）、训练
- **本月**：饮食 / 训练达标天数和日历
- **我的**：身体数据、体重折线图和身材剪影
- **规则**：只读规则、配色切换（黑金 / 红金）、导出导入备份、审批人入口
- **审批人界面**（需要密码）：审核豁免、确认月度结算、修改规则（下个月 1 号起生效）

## 开发

```bash
npm install
npm run dev      # 本地预览，地址后面加 ?demo 看演示数据
npm test         # 单元测试
npm run build    # 打包到 dist/
npm run icons    # 重新生成 App 图标
npm run deploy   # 测试 + 打包 + 发布到 GitHub Pages
```

发布方式：`npm run deploy` 把打包好的 `dist/` 推到 `gh-pages` 分支，GitHub Pages 从这个分支提供网页。
